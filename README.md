# 🚀 QA Journey (qa-uzbekistan)

> O'zbekistondagi ilk ochiq manbali QA (Quality Assurance) ta'lim platformasi va qo'llanmasi.

Ushbu platforma dasturiy ta'minot sifatini ta'minlash sohasiga qiziquvchilar, yangi o'rganuvchilar va amaliyotdagi QA muhandislari uchun mo'ljallangan.

---

## 🧭 Asosiy bo'limlar

- 🎯 **[QA Roadmap](/roadmap)** — Noldan SDET / Senior QA darajasigacha bosqichma-bosqich yo'l xaritasi.
- 📘 **[Manual QA](/manual)** — SDLC va STLC, Test darajalari va turlari, Test dizayn texnikalari (BVA, EP), Test Case va Bug Report yozish.
- ⚡ **[API Testing](/api-testing)** — REST arxitekturasi, HTTP status kodlari, Postman va avtomatik test skriptlari.
- 🤖 **[QA Automation](/automation)** — Zamonaviy Playwright freymvorki, birinchi test va Page Object Model (POM).
- 💼 **[QA Intervyu](/interview)** — Texnik suhbatlarda eng ko'p beriladigan fundamental savollar va mukammal javoblar.

## 🛠️ Loyihani kompyuterda ishga tushirish

```bash
# Repozitoriyni klonlash
git clone https://github.com/Ergashov15/qa-uzbekistan.git
cd qa-uzbekistan

# Bog'liqliklarni o'rnatish
npm install

# Lokal serverni ishga tushirish
npm run dev
```

Brauzerda oching: **[http://localhost:3000](http://localhost:3000)**

---

## 🏗️ Production Build

```bash
npm run build
npm run start
```
