# Software Testing: Dasturiy Ta'minotni Sinash Asoslari

**Software Testing (Dasturiy ta'minotni sinash)** — dasturiy mahsulotning belgilangan texnik talablarga to'liq javob berishini tekshirish, kutilayotgan va amaldagi natijalar o'rtasidagi tafovutlarni (nuqsonlarni) aniqlash hamda mahsulotning sifati, xavfsizligi va ishonchliligini baholashga qaratilgan fundamental muhandislik jarayonidir.

Har qanday zamonaviy dasturiy ta'minot foydalanuvchiga taqdim etilishidan oldin to'liq sinovdan o'tishi shart. Aks holda, kichik bir dasturiy nosozlik katta moliyaviy yo'qotishlarga yoki insonlar xavfsizligiga tahdid solishi mumkin.

---
