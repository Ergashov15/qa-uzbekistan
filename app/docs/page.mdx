# Dasturiy Ta'minotni Sinash (QA) Qo'llanmalari

Dasturiy ta'minot sifatini ta'minlash (Quality Assurance) sohasiga oid barcha fundamental nazariy bilimlar, hayotiy sikllar, sinov darajalari va metodologiyalar to'plami.

Ushbu o'quv dasturi xalqaro **TpointTech Software Testing Tutorial** hamda **ISTQB** standartlari asosida to'liq adabiy o'zbek tilida bayon etilgan.

---
