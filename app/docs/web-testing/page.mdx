# Veb Texnologiyalari va Chuqur Sinov (Web Testing)

Ushbu modulda veb-ilovalarni chuqur tahlil qilish uchun zarur bo'lgan brauzer mexanizmlari o'rganiladi.

## Veb sinovida nimalarga e'tibor berish lozim?

1. **Brauzer keshining (Cache) ta'siri:** Dasturchi yangi kod chiqardi, lekin foydalanuvchi kompyuterida eski JS/CSS keshlanib qolgani sababli sayt buzilib ko'rinishi mumkin.
2. **Xotiradagi ma'lumotlar xavfsizligi:** Tokenlar va parollar ochiq holda `localStorage` ga yozilmaganligini nazorat qilish.
3. **Turli brauzerlar rendering dvigatellari:** Chrome (Blink), Safari (WebKit) va Firefox (Gecko) o'rtasidagi vizual farqlar.
