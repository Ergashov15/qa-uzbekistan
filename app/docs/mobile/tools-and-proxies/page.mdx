# Mobil Sinov Asboblari: ADB va Proksi (Charles / Proxyman)

Professional mobil QA muhandisi telefon ekraniga shunchaki bosib o'tirmaydi — u telefonning ichki loglarini o'qiydi va smartfondan serverga ketayotgan tarmoq trafigini to'xtatib tahlil qila oladi.

---

## 1. ADB (Android Debug Bridge) asoslari

**ADB** — bu kompyuter orqali Android smartfon bilan buyruqlar satrida (Terminal) to'g'ridan-to'g'ri muloqot qilish imkonini beruvchi rasmiy Google vositasi.

### Eng muhim QA buyruqlari:

```bash
# Kompyuterga ulangan barcha qurilmalarni ko'rish
adb devices

# Yangi .apk faylni telefonga o'rnatish
adb install -r app-release.apk

# Ilovani o'chirish (Uninstall)
adb uninstall com.company.ourapp

# Ilovaning barcha kesh va ma'lumotlarini tozalash (xuddi yangi o'rnatilgandek qilish)
adb shell pm clear com.company.ourapp
```

### Crash loglarni ushlash (`adb logcat`):
Agar dastur to'satdan yopilib ketgan bo'lsa (Crash), dasturchiga xatoni tuzatishi uchun xatolik logi kerak bo'ladi:
```bash
# Faqat xatoliklarni (Error darajasi) filtrlab ko'rish
adb logcat *:E > crash_log.txt
```

## 2. Tarmoq proksilari (Charles Proxy / Proxyman)

Brauzerda DevTools ochib `Network` oynasida API so'rovlarni ko'rish mumkin, ammo mobil ilovalarda bunday oyna yo'q. Mobil trafikni ko'rish va o'zgartirish uchun **Man-in-the-Middle (MitM)** proksi dasturlari ishlatiladi:
* **Charles Proxy** (Windows, macOS)
* **Proxyman** (Zamonaviy va qulay interfeys, macOS/Windows)

```
[Mobil Ilova] ────► [Charles / Proxyman Proksi] ────► [Backend Server]
                     │
                     ├─ So'rov va javoblarni ko'rish (JSON)
                     ├─ SSL sertifikat orqali HTTPS ni ochish
                     ├─ Sekin internetni simulyatsiya qilish (Throttling)
                     └─ Backend javobini o'zgartirish (Mocking / Breakpoint)
```

### QA uchun eng muhim 3 ta proksi imkoniyati:

### 2.1. Trafikni sekinlashtirish (Network Throttling):
Sun'iy ravishda internet tezligini tushirib qo'yish (masalan, 2G yoki yuqori kechikishli 3G). Bu orqali ilovaning yuklanish animatsiyalari va timeout sozlamalari tekshiriladi.

### 2.2. Breakpoint va Map Local (Ma'lumotlarni soxtalashtirish):
Backend hali tayyor bo'lmaganda yoki serverdagi xatolikni tekshirish uchun:
* Serverdan kelayotgan `200 OK` javobini proksida to'xtatib, uning o'rniga `500 Internal Server Error` qaytarish;
* Ilova bu paytda qanday xabar ko'rsatishini ko'rish.

### 2.3. SSL Pinning va sertifikatlar:
Telefonda HTTPS trafigini ko'rish uchun qurilmaga maxsus Charles / Proxyman Root sertifikatini o'rnatish talab qilinadi.
