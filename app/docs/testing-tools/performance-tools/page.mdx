# Yuklama Sinov Vositalari (Performance & Load Tools)

Tizimga minglab yoki millionlab virtual foydalanuvchilar oqimini simulyatsiya qilish uchun maxsus quvvatli yuklama sinov vositalari qo'llaniladi.

---

## 1. Apache JMeter (Klassik Gigant)

- **Platforma:** 100% Java asosida yaratilgan, dunyodagi eng ommabop bepul yuklama sinov dasturi.
- **Qo'llab-quvvatlaydigan protokollari:** HTTP, HTTPS, REST, SOAP, JDBC (ma'lumotlar bazasini to'g'ridan-to'g'ri yuklash), FTP, TCP, JMS.
- **Xususiyatlari:** Qulay grafik interfeys (GUI) orqali test rejasini tuzish, parametrlashtirish (CSV fayllardan foydalanuvchi ma'lumotlarini o'qish), Assertions (javob to'g'riligini tekshirish) va vizual hisobotlar (HTML Dashboard).
- **Tavsiya:** Testlarni tuzish uchun GUI rejimidan, haqiqiy og'ir yuklamani berish uchun esa buyruqlar satridan (Non-GUI / CLI mode) foydalaniladi.

---

## 2. Grafana k6 (Zamonaviy Dasturchilar Tanlovi)

- **Platforma:** Go tilida yozilgan o'ta yengil va tezkor, skriptlari esa zamonaviy JavaScript (ES6) tilida yoziladigan yangi avlod yuklama sinov vositasi.
- **Afzalliklari:**
  - Resurslarni (RAM va CPU) JMeter ga nisbatan 5-10 barobarga kamroq sarflaydi.
  - Kod shaklida yoziladi ("Load Testing as Code"): GitHub/GitLab repozitoriylarida saqlash va CI/CD ga ulash nihoyatda oson.
  - Grafana va Prometheus bilan mukammal integratsiyalashib, natijalarni jonli efirda chiroyli ko'rsatadi.

---

## JMeter va k6 Qiyosi

| Mezon | Apache JMeter | Grafana k6 |
| :--- | :--- | :--- |
| **Interfeys** | Vizual GUI (Desktop ilova) | CLI (Buyruqlar satri) |
| **Skript tili** | XML / Groovy | JavaScript (ES6) |
| **Resurs sarfi** | Yuqori (Java JVM xotirasi) | **O'ta past (Go dvigateli)** |
| **CI/CD mosligi** | Sozlash biroz murakkab | **Tug'ma oson (Native CI/CD)** |
| **Protokollar boyligi** | De-fakto barcha tarmoq protokollari | Asosan HTTP, WebSockets, gRPC |
