# Kuchli QA Portfoliosi va Rezyume Yaratish

Yuzlab yangi bitiruvchilar orasidan darhol ishga kirishning yagona siri — bu quruq so'zlar emas, balki **amaliy ko'rsatib bo'ladigan portfolio**dir.

---

## 1. QA Portfoliosi nimalardan iborat bo'lishi kerak?

Hech qanday tijoriy ish tajribangiz bo'lmasa ham, ochiq veb-saytlar (masalan, mashhur onlayn do'konlar yoki demo banking ilovalari) asosida quyidagi 4 ta loyihani tayyorlab, GitHub va LinkedIn profilingizga joylashingiz mumkin:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        QA GITHUB PORTFOLIO                             │
├──────────────────────────────────┬─────────────────────────────────────┤
│ 1. Avtomatlashtirish Repozitoriysi│ 2. Postman API Kolleksiyasi         │
│ • Playwright (TypeScript/JS)     │ • 15-20 ta so'rov, Environment     │
│ • Page Object Model (POM)        │ • Assertion test skriptlari         │
│ • GitHub Actions CI yashil badge │ • Newman orqali yurgizish yo'riqnomasi│
├──────────────────────────────────┼─────────────────────────────────────┤
│ 3. Test Hujjatlari (Docs)        │ 4. Namunaviy Bug Reportlar          │
│ • Test Plan (PDF yoki Markdown)  │ • Jira/Notion uslubidagi chiptalar  │
│ • XMind / Miro Test xaritasi     │ • Loglar, skrinshotlar va cURL      │
└──────────────────────────────────┴─────────────────────────────────────┘
```

1. **GitHub Avtotest Repozitoriyasi:** Playwright yoki Cypress da yozilgan E2E testlar. `README.md` faylida testlarni bitta buyruq bilan qanday ishga tushirish aniq ko'rsatilgan bo'lishi shart.
2. **Postman Kolleksiyasi:** Har bir so'rovda avtomatik tekshiruv skriptlari (`pm.expect(pm.response.code).to.eql(200)`) yozilgan to'liq kolleksiya.
3. **Namunaviy Bug Reportlar:** Ochiq manbali saytlarda topilgan 3-4 ta haqiqiy va chiroyli rasmiylashtirilgan xatolik hisoboti.

---

## 2. Rezyumeda natijalarni raqamlar bilan ko'rsatish

Ko'p nomzodlar rezyumesiga: *"Test caselar yozdim, buglar topdim va API larni testladim"* deb zerikarli tavsif berishadi. Bu ish beruvchida hech qanday taassurot qoldirmaydi.

### Google tavsiya etgan "XYZ Formulasi":
> **"Men [Z] amalini bajarib, [Y] ko'rsatkich orqali o'lchanadigan [X] natijaga erishdim."**

### Qiyosiy misollar:

| Oddiy va zerikarli tavsif | Kuchli va professional tavsif |
| :--- | :--- |
| *"Saytni qo'lda testladim va xatolarni dasturchilarga yubordim."* | *"Asosiy to'lov va ro'yxatdan o'tish modullari uchun 60+ test caselar ishlab chiqdim va relizdan oldin 14 ta kritik bugni aniqlab, moliyaviy xatarlarni bartaraf etdim."* |
| *"Postman va Playwright da testlar yozdim."* | *"Playwright orqali 45 ta regressiya testini avtomatlashtirib, har bir relizni sinash vaqtini 5 soatdan 15 daqiqagacha (95% ga) qisqartirdim."* |

---

## 3. Xalqaro bozorga chiqish (Remote Work)

Ingliz tilida erkin muloqot qila oladigan va texnik ko'nikmalari (API + Automation) kuchli bo'lgan QA mutaxassislari uchun global imkoniyatlar:
* **LinkedIn:** Profilingizni to'liq ingliz tilida yuritish va muntazam ravishda QA tahliliy postlarini ulashib borish;
* **Upwork / Fiverr / Testlio:** Dastlabki buyurtmalarni bajarib, haqiqiy xalqaro mijozlar bilan ishlash tajribasini to'plash;
* **Open Source loyihalar:** GitHub dagi mashhur ochiq loyihalarning xatolarini topib, Issue va Pull Request ochish.
