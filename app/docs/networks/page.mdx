# Tarmoqlar va Web Asoslari (Networks for QA)

Har bir dasturiy ta'minot sinovchisi (QA Engineer) tizimning qanday ishlashini, mijoz va server o'rtasidagi muloqotni, ma'lumotlar almashinuvi protokollarini hamda veb-texnologiyalarni chuqur tushunishi shart.

Ushbu bo'limda tarmoq arxitekturasi, asosiy protokollar, API standartlari va veb-muhitning eng muhim tushunchalari tizimlashtirilgan holda taqdim etilgan.
