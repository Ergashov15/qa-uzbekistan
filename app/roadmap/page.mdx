# QA Engineer Yo'l Xaritasi (Roadmap) va Loyiha Maqsadlari

Ushbu yo'l xaritasi O'zbekistonda **Quality Assurance (QA)** sohasini noldan o'rganayotgan yangi mutaxassislar hamda amaliyotdagi muhandislar uchun tizimli o'quv rejasini, shuningdek, **QA COMPASS** ochiq ta'lim platformasining real maqsadlari va hozir qilinayotgan ishlarini o'z ichiga oladi.

---

## 🎯 Loyiha Maqsadlari va Hozirgi Holat

QA COMPASS — O'zbekiston IT hamjamiyatida xalqaro standartlar (ISTQB) va zamonaviy amaliyotga asoslangan birinchi keng qamrovli, ochiq manbali o'zbek tilidagi QA bilimlar bazasidir.

### 1. Real Maqsadlarimiz
- **Sifatli ochiq ta'lim:** Har bir o'rganuvchi uchun bepul, tizimlashtirilgan va adabiy o'zbek tilidagi to'liq QA darsliklarini taqdim etish.
- **Nazariya va amaliyot uyg'unligi:** Quruq ta'riflardan qochib, real IT loyihalarida (e-tijorat, bank, to'lov tizimlari) qo'llaniladigan amaliy keyslarni yoritish.
- **Karyeraga ko'mak:** Talabgor mutaxassis bo'lish uchun zarur bo'lgan texnik bilimlar, test hujjatlari andozalari hamda intervyu savollari bazasini yaratish.

## 🧭 QA Engineer Kasbiy O'quv Rejasi

Yangi boshlovchilar uchun noldan boshlab kuchli **Manual QA**, **QA Engineer** yoki **SDET (Software Development Engineer in Test)** bo'lishgacha bo'lgan bosqichma-bosqich yo'l:

<Steps>

### 1-bosqich: Kompyuter va Web texnologiyalari asoslari

Har qanday sinovchi birinchi navbatda dastur va internet qanday ishlashini chuqur tushunishi kerak:

- **Mijoz-Server (Client-Server) arxitekturasi:** Frontend, Backend va Ma'lumotlar bazasi qanday bog'lanadi?
- **Internet va Tarmoqlar:** HTTP/HTTPS protokollari, DNS, IP manzillar, so'rov va javob (Request/Response) tuzilishi.
- **Ma'lumotlar formati:** JSON va XML nima, ularning sintaksisi va ma'lumot uzatishdagi o'rni.
- **Brauzer DevTools:** Elements (DOM tahlili), Console (xatoliklarni kuzatish), Network (API so'rovlar, status kodlar), Application (Cookie, LocalStorage, SessionStorage).

### 2-bosqich: Dasturiy ta'minotni sinash nazariyasi (Software Testing Fundamentals)

Sifatli testlashning asosi mustahkam xalqaro standartlarga (ISTQB) tayanadi:

- **SDLC va STLC:** Dasturni ishlab chiqish va sinash hayotiy sikllari, ularning farqlari va o'zaro bog'liqligi.
- **Sinovning 7 ta oltin tamoyili:** Nuqsonlar borligi, to'liq sinovning imkonsizligi, pestitsid paradoksi va h.k.
- **SDLC Modellari:** Sharshara (Waterfall), V-Model, Spiral, Prototip hamda Agile (Scrum/Kanban) doirasida sinov.
- **Sinov darajalari:** Unit testing, Integration testing, System testing va Acceptance testing (UAT, Alpha/Beta).

### 3-bosqich: Sinov turlari katalogi va Mobil Sinov (Types of Testing & Mobile QA)

Ilovalarni har tomonlama tekshirish uchun barcha asosiy sinov turlari va mobil muhit xususiyatlarini o'rganish:

- **Funksional sinovlar:** [Smoke testing](/docs/types-of-testing/smoke-testing), [Sanity testing](/docs/types-of-testing/sanity-testing), [Regression testing](/docs/types-of-testing/regression-testing), [Integration testing](/docs/types-of-testing/manual-testing/types-of-manual-testing/black-box-testing/types-of-black-box/functional-testing/types-of-functional-testing/integration-testing).
- **Nofunksional sinovlar:** [Performance (Unumdorlik)](/docs/types-of-testing/manual-testing/types-of-manual-testing/black-box-testing/types-of-black-box/non-functional-testing/types-of-non-functional-testing/performance-testing), [Load (Yuklama)](/docs/types-of-testing/load-testing), [Stress](/docs/types-of-testing/stress-testing), [Xavfsizlik (Security)](/docs/types-of-testing/security-testing), [Moslashuvchanlik (Compatibility)](/docs/types-of-testing/manual-testing/types-of-manual-testing/black-box-testing/types-of-black-box/non-functional-testing/types-of-non-functional-testing/compatibility-testing).
- **Mobil ilovalarni sinash (Mobile QA):** [Mobil Sinov Markazi](/docs/mobile-testing) — Nativ, Gibrid, PWA, Interrupt sinovlari, tarmoq o'zgarishi, emulyatorlar va ADB buyruqlari.
- **Maxsus yo'nalishlar:** [Exploratory testing](/docs/types-of-testing/exploratory-testing), [Adhoc testing](/docs/types-of-testing/adhoc-testing), [GUI testing](/docs/types-of-testing/gui-testing), [Accessibility testing](/docs/types-of-testing/accessibility-testing) va [Test strategiyasi](/docs/types-of-testing/test-strategy).

### 4-bosqich: Test dizayn texnikalari (Test Design Techniques)

Minimal miqdordagi test-keyslar bilan maksimal xatoliklarni topish mahorati:

- **Qora quti texnikalari (Black-Box):**
  - Ekvivalentlik sinflariga bo'lish (Equivalence Partitioning - EP)
  - Chegaraviy qiymatlar tahlili (Boundary Value Analysis - BVA)
  - Qarorlar jadvali (Decision Table Testing)
  - Holatlar o'tishi (State Transition Testing)
  - Foydalanish ssenariylari (Use Case Testing)
- **Oq quti texnikalari (White-Box):**
  - Operatorlar qamrovi (Statement Coverage)
  - Tarmoqlar qamrovi (Branch Coverage)
  - Qarorlar va ma'lumotlar oqimi sinovlari (Decision / Data Flow Testing)

### 5-bosqich: Test hujjatlari va Nuqsonlarni boshqarish

Professional QA muhandisi o'z fikrini tizimli va tushunarli hujjatlashtira olishi zarur:

- **Hujjatlar:** Test Plan, Test Strategy, Test Scenarios, Test Cases, Checklists, RTM (Requirement Traceability Matrix).
- **Nuqsonlar hayotiy sikli (Defect Life Cycle):** Yangi, Tasdiqlangan, Tuzatilgan, Qayta sinovdan o'tgan, Yopilgan.
- **Bug Report tuzilishi:** Qisqa xulosa (Summary), Takrorlash qadamlari (Steps to Reproduce), Kutilgan vs Amaldagi natija, Skrinshot va loglar.
- **Severity vs Priority:** Xatoning tizimga texnik ta'siri hamda biznes uchun ustuvorligini to'g'ri belgilash.
- **Vositalar:** Jira, TestRail, Qase, Bugzilla, Trello.

### 6-bosqich: Ma'lumotlar bazasi (SQL) va API sinovlari

Faqat foydalanuvchi interfeysi (UI) bilan cheklanib qolmasdan, tizimning ichki qatlamlarini tekshirish:

- **SQL asoslari:** `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, funksiyalar (`COUNT`, `SUM`, `AVG`).
- **Jadvallar integratsiyasi:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, ma'lumotlar yaxlitligi (ACID).
- **RDBMS vositalari:** PostgreSQL, MySQL, DBeaver.
- **REST API tamoyillari:** HTTP metodlari (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`), URL tuzilishi, Status kodlar (2xx, 3xx, 4xx, 5xx).
- **API vositalari:** Postman (muhit o'zgaruvchilari, test skriptlari yozish, kolleksiyalar), Swagger / OpenAPI, Charles Proxy / Fiddler.

### 7-bosqich: Testlarni Avtomatlashtirish (QA Automation)

Regressiya va takroriy sinovlarni dasturiy kod orqali avtomatlashtirish:

- **Dasturlash tili:** TypeScript / JavaScript yoki Python (sohada eng ko'p talab qilinadigan tillar).
- **Web UI Automation:**
  - **Playwright** (Zamonaviy, tezkor, auto-wait va ko'p brauzerli — tavsiya etiladi)
  - **Cypress**
  - **Selenium WebDriver**
- **Arxitektura va andozalar:** Page Object Model (POM), test ma'lumotlarini boshqarish, Clean Code prinsiplari.
- **API Automation:** Playwright API testing, Python `pytest` + `requests` yoki Supertest.

### 8-bosqich: CI/CD, DevOps vositalari va Karyera

Avtotestlarni umumiy dastur yetkazib berish quvuriga (pipeline) ulash hamda ishga joylashish:

- **Versiyalar nazorati:** Git, GitHub / GitLab (branching, pull request, review).
- **CI/CD quvurlari:** GitHub Actions yoki GitLab CI orqali har bir yangi kodda avtotestlarni avtomatik yurgizish.
- **Hisobotlar:** Allure Report integratsiyasi.
- **Intervyu va Karyera:** [Fundamental va situatsion intervyu savollari](/interview), professional rezyume tuzish, GitHub portfoliosini shakllantirish.

</Steps>
