# QA Engineer Yo'l Xaritasi (Roadmap) va Xalqaro Standartlar

Ushbu yo'l xaritasi xalqaro **ISTQB (International Software Testing Qualifications Board)**, **ISO/IEC/IEEE 29119** hamda zamonaviy **Software Quality Engineering** standartlari asosida ishlab chiqilgan.

Yo'l xaritasi noldan boshlovchilardan tortib **Senior QA / SDET** darajasigacha bo'lgan bosqichma-bosqich rivojlanish strategiyasini, har bir bosqichdagi standartlarni hamda **QA COMPASS** platformasidagi tegishli o'quv materiallarini o'z ichiga oladi.

---

## 🏛️ Xalqaro Sifat va Sinov Standartlari Matritsasi

Zamonaviy professional test muhandisi (QA Engineer) o'z faoliyatini quyidagi jahon standartlari asosida olib boradi:

| Standart | To'liq nomi va maqsadi | Qo'llanilish sohasi |
| :--- | :--- | :--- |
| **ISTQB CTFL v4.0** | *Certified Tester Foundation Level* — Sinovning jahon bo'yicha yagona terminologik va metodik asosi | Fundamental tamoyillar, test tahlili, dizayn texnikalari va test boshqaruvi |
| **ISO/IEC/IEEE 29119** | *Software Testing Standards (1–5 qismlar)* — Dasturiy sinovning xalqaro rasmiy standarti | Sinov jarayonlari, test hujjatlari andozalari va sinov texnikalari |
| **ISO/IEC 25010** | *System and Software Quality Models* — Sifat xususiyatlari va metrikalari | Funksional, unumdorlik, xavfsizlik, qulaylik (UX) va barqarorlik talablari |
| **IEEE 829** | *Standard for Software and System Test Documentation* | Test Plan, Test Case, Test Log va Defect Report strukturasi |
| **W3C WCAG 2.2** | *Web Content Accessibility Guidelines* | Inklyuzivlik va qulaylik (Accessibility testing) standartlari |
| **OWASP ASVS / Top 10** | *Open Worldwide Application Security Project* | Dasturiy ta'minot va veb-ilovalarning xavfsizlik sinovlari |

## 🧭 Karyera Bosqichlari va Malaka Matritsasi (Competency Matrix)

```
[Trainee / Intern QA] 
        │
        ▼
[Junior Manual QA] ────► [ISTQB CTFL Asoslari + Test Dizayn + Test Hujjatlari]

[Middle QA Engineer] ──► [API Testing + SQL + Mobile QA + Test Management]

```

## 🚀 Standartlashtirilgan Bosqichma-bosqich O'quv Rejasi

<Steps>

### 1-bosqich: Kompyuter tarmoqlari, Web arxitektura va Muhit asoslari

Dasturiy mahsulotni sinashdan oldin uning texnik arxitekturasi va internet qanday ishlashini bilish shart:

- **Mijoz-Server arxitekturasi:** [Client-Server tushunchasi](/docs/networks/client-server-architecture), Frontend va Backend bog'liqligi.
- **Web tarmoq protokollari:** [HTTP va HTTPS protokollari](/docs/networks/http), [OSI va TCP/IP modellari](/docs/networks/osi-and-tcp-ip-models), DNS va IP tizimi.
- **Arxitektura turlari:** [Mikroservis arxitekturasi](/docs/networks/microservice-architecture), [Veb-xizmatlar](/docs/networks/web-service), [REST, SOAP va gRPC](/docs/networks/rest-soap-grpc).
- **Brauzer va Ma'lumotlarni saqlash:** [Kesh mexanizmlari](/docs/networks/cache), [Mijoz tomonida saqlash (Cookies, LocalStorage, SessionStorage)](/docs/networks/client-side-storage), Chrome DevTools (Console, Network, Application).

### 2-bosqich: Sinov nazariyasi va ISTQB CTFL v4.0 Standartlari

Xalqaro standartlarga mos umumiy terminologiya va asosiy sinov qonuniyatlarini egallash:

- **Sinovning 7 ta oltin tamoyili:** [Software Testing tamoyillari](/docs/software-testing/software-testing-principles) (Pestitsid paradoksi, to'liq sinovning imkonsizligi, nuqsonlar klasteri).
- **ISTQB Fundamental tushunchalari:** [Sinov asoslari (Fundamentals of Testing)](/docs/istqb-foundation/fundamentals-of-testing), xato (Error), nuqson (Defect) va nosozlik (Failure) farqlari.
- **Hayotiy sikllar:** [SDLC](/docs/software-testing/software-development-life-cycle) va [STLC](/docs/software-testing/software-testing-life-cycle) bosqichlari, [SDLC modellari (Waterfall, Agile, V-Model, Spiral)](/docs/sdlc-models).
- **Sinov darajalari:** [Levels of Testing](/docs/software-testing/levels-of-testing) (Unit, Integration, System, Acceptance).
- **Statik sinov:** [Statik testlash va ko'rib chiqish jarayonlari](/docs/istqb-foundation/static-testing) (Reviews, Walkthrough, Technical Review, Inspection).

### 3-bosqich: Standart Test Dizayn Texnikalari (ISO/IEC/IEEE 29119-4)

Kam sonli testlar yordamida maksimal nuqsonlarni aniqlash metodikasi:

- **Qora quti texnikalari (Black-Box Techniques):**
  - Ekvivalentlik sinflariga ajratish (*Equivalence Partitioning - EP*)
  - Chegaraviy qiymatlar tahlili (*Boundary Value Analysis - BVA*)
  - Qarorlar jadvali (*Decision Table Testing*)
  - Holatlar o'tishi (*State Transition Testing*)
  - Foydalanish ssenariylari (*Use Case Testing*)
- **Oq quti texnikalari (White-Box Techniques):**
  - Operatorlar qamrovi (*Statement Coverage*)
  - Tarmoqlar qamrovi (*Branch Coverage*)
  - [ISTQB Test Analysis & Design to'liq bo'limi](/docs/istqb-foundation/test-analysis-and-design) va [Test Texnikalari Markazi](/docs/test-techniques).
- **Tajribaga asoslangan texnikalar (Experience-Based):**
  - Xatolarni taxmin qilish (*Error Guessing*), Tadqiqotchi sinov (*Exploratory Testing*), Cheklist asosida sinov (*Checklist-Based*).

### 4-bosqich: Sinov Turlari Katalogi va ISO/IEC 25010 Sifat Modeli

Dasturiy tizimni barcha sifat atributlari bo'yicha har tomonlama tekshirish:

- **Funksional sinovlar:** [Smoke testing](/docs/types-of-testing/smoke-testing), [Sanity testing](/docs/types-of-testing/sanity-testing), [Regression testing](/docs/types-of-testing/regression-testing).
- **Nofunksional sinovlar (ISO 25010):**
  - Unumdorlik va Yuklama: [Load testing](/docs/types-of-testing/load-testing), [Stress testing](/docs/types-of-testing/stress-testing).
  - Xavfsizlik: [Security testing asoslari](/docs/types-of-testing/security-testing), OWASP tamoyillari.
  - Moslashuvchanlik va Qulaylik: [Moslashuvchanlik](/docs/types-of-testing), [Accessibility testing (WCAG)](/docs/types-of-testing/accessibility-testing).
- Batafsil ma'lumot: [Sinov Turlari To'liq Katalogi](/docs/types-of-testing).

### 5-bosqich: Test Hujjatlari va Nuqsonlarni Boshqarish (ISO/IEC/IEEE 29119-3 & IEEE 829)

Professional test muhandisining rasmiy hujjat yuritish mahorati:

- **Asosiy test artefaktlari:** [Test Hujjatlari Markazi](/docs/test-documentation)
  - Test Plan va Test Strategy (Sinov strategiyasi va ko'lami)
  - Test Scenario, Test Case va Test Suite
  - Talablar kuzatuvchanlik matritsasi (Requirement Traceability Matrix - RTM)
  - Test xulosasi hisoboti (Test Summary Report)
- **Nuqsonlarni kuzatish va hayotiy sikli:** [Nuqsonlarni Kuzatish Markazi](/docs/defect-tracking)
  - Defect Life Cycle (New -> Assigned -> In Progress -> Fixed -> Verified -> Closed)
  - Bug Report anatomiyasi: Title, Steps to Reproduce, Expected vs Actual Result, Severity & Priority
  - Boshqaruv vositalari: Jira, TestRail, Qase.
- **Sinov faoliyatini boshqarish:** [ISTQB Managing Test Activities](/docs/istqb-foundation/managing-the-test-activities) va [Test Menejment](/docs/test-management).

### 6-bosqich: Ma'lumotlar Bazasi (SQL) va API Testlash

Foydalanuvchi interfeysidan (UI) chuqurroq darajada tizim ma'lumotlari va biznes mantig'ini tekshirish:

- **RDBMS va SQL asoslari:**
  - `SELECT`, `INSERT`, `UPDATE`, `DELETE` (CRUD amallari)
  - Filtrlash va saralash: `WHERE`, `LIKE`, `IN`, `BETWEEN`, `ORDER BY`
  - Agregat funksiyalar va guruhlash: `COUNT`, `SUM`, `AVG`, `GROUP BY`, `HAVING`
  - Jadvallarni birlashtirish: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`
  - Tranzaksiyalar va ACID tamoyillari. Vositalar: PostgreSQL, DBeaver.
- **API sinovlari:**
  - RESTful API prinsiplari, HTTP metodlari (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`)
  - HTTP Status kodlari (2xx Muvaffaqiyat, 3xx Yo'naltirish, 4xx Mijoz xatosi, 5xx Server xatosi)
  - Postman amaliyoti: Muhit o'zgaruvchilari (Environment Variables), Test skriptlari (`pm.test`, `pm.expect`), Kolleksiyalarni avtomatlashtirish (Collection Runner, Newman).

### 7-bosqich: Mobil Ilovalarni Sinash (Mobile QA)

Mobil platformalar (Android va iOS) o'ziga xos xususiyatlari bo'yicha sinov:

- **Ilova turlari:** Nativ (Native), Gibrid (Hybrid), Veb / PWA ilovalar.
- **Mobilga xos testlar:** Uzilishlar sinovi (*Interrupt testing* — qo'ng'iroq, SMS, batareya quvvati kamayishi), Tarmoq tezligi o'zgarishi (2G/3G/4G/Offline rejim).
- **Qurilmalar va Vositalar:** Emulyator va Simulyatorlar, Haqiqiy qurilmalar fermasi, Android Debug Bridge (ADB) buyruqlari, loglarni yig'ish (Logcat, Console).
- Batafsil: [Mobil Sinov Markazi](/docs/mobile-testing).

### 8-bosqich: Testlarni Avtomatlashtirish (QA Automation / SDET)

Regressiya va barqaror sinovlarni dasturiy kod vositasida avtomatlashtirish:

- **Dasturlash tili:** Zamonaviy test muhitida eng ommabop tillardan biri — **TypeScript / JavaScript** yoki **Python**.
- **E2E Test Freymvorki:** **Playwright** (Tavsiya etiladi: tezkor, auto-wait, parallel bajarilish, ko'p brauzerli, shaffof report tizimi).
- **Arxitektura andozalari:** Page Object Model (POM), komponentlar abstraksiyasi, test ma'lumotlarini ajratish (fixtures).
- **API Avtomatlashtirish:** Playwright API testing, Supertest yoki Python `pytest` + `requests`.
- Ekosistema haqida: [Sinov Vositalari Sharhi](/docs/testing-tools).

### 9-bosqich: CI/CD, DevOps va Sifat Boshqaruvi (Quality Engineering)

Avtotestlarni umumiy yetkazib berish konveyeriga (Continuous Integration) bog'lash:

- **Versiyalar nazorati:** Git asoslari (Branching strategiyalari, Pull Request, Code Review).
- **CI/CD Quvurlari:** GitHub Actions yoki GitLab CI orqali avtotestlarni har bir PR yoki kechki rejada (Nightly runs) yurgizish.
- **Konteynerlashtirish:** Docker orqali izolyatsiyalangan test muhitini yaratish.
- **Sifat hisobotlari va metrikalari:** Allure Report integratsiyasi, Defect Detection Percentage (DDP), Defect Removal Efficiency (DRE).

### 10-bosqich: Xalqaro Sertifikatlar, Rezyume va Kasbiy Karyera

Nazariy va amaliy bilimlarni xalqaro sertifikat hamda kuchli portfolio bilan tasdiqlash:

- **Xalqaro sertifikatlar:**
  - **ISTQB CTFL** (Certified Tester Foundation Level) — barcha QA muhandislari uchun oltin standart.
  - **ISTQB CTFL-AT** (Agile Tester) — Agile jamoalar uchun ixtisoslashuv.
- **Rezyume va Portfolio:** GitHub'da Playwright yoki Postman bo'yicha toza arxitekturali loyihalar, LinkedIn profilini optimallashtirish.
- **Karyera va Kasbiy Tayyorgarlik:** Fundamental testlash, amaliy situatsion keyslar hamda texnik topshiriqlarni mustaqil bajarish ko'nikmalarini rivojlantirish.

</Steps>
