# Mobil Sinov Asoslari: Ilovalar Turlari va Ekotizimlar

Mobil ilovani sinashga kirishishdan avval uning texnik arxitekturasi va qaysi operatsion tizimga mo'ljallanganini aniq bilish kerak.

---

## 1. Mobil ilovalar arxitekturasi

| Tur | Texnologiyalar | Afzalligi | Kamchiligi (QA ko'zi bilan) |
| :--- | :--- | :--- | :--- |
| **Native Apps (Mahalliy)** | Swift / Objective-C (iOS), Kotlin / Java (Android) | Eng yuqori tezlik, qurilmaning barcha sensorlariga (FaceID, GPS, Kamera) to'liq kirish. | Ikkala platforma uchun alohida kod yoziladi, ikkala platformada alohida testlash talab etiladi. |
| **Cross-Platform / Hybrid** | Flutter, React Native | Bitta kod bazasi ham iOS, ham Android uchun ishlaydi. Ishlab chiqish tez va arzon. | Ba'zi murakkab animatsiyalar sekinlashishi, platformalar o'rtasida UI farqlari paydo bo'lishi mumkin. |
| **PWA (Progressive Web App)** | HTML, CSS, JavaScript | O'rnatish shart emas, brauzer orqali ishlaydi, yangilanish bir zumda bo'ladi. | Telefon imkoniyatlaridan (Bluetooth, chuqur xotira) foydalanish cheklangan. |

---

## 2. iOS va Android o'rtasidagi farqlar

Dasturni testlayotganda quyidagi fundamental farqlarni inobatga olish shart:

### 2.1. "Ortga" (Back) tugmasining ishlashi:
* **Android:** Qurilmaning pastki qismida jismoniy yoki imo-ishorali (gesture) umumtizim "Back" tugmasi mavjud. U ilovaning istalgan ekranida bitta qadam orqaga qaytishi kerak.
* **iOS:** Maxsus apparat "Back" tugmasi yo'q. Dastur ichida yuqori chap burchakda havola bo'lishi yoki chapdan o'ngga surish (Swipe to back) qo'llab-quvvatlanishi kerak.

### 2.2. Operatsion tizim versiyalari va fragmentatsiya:
* **iOS:** Apple foydalanuvchilarining 80-90% qismi eng so'nggi 2 ta iOS versiyasida yuradi. Qurilmalar soni cheklangan (iPhone modellari).
* **Android:** Yuzlab smartfon ishlab chiqaruvchilari (Samsung OneUI, Xiaomi HyperOS/MIUI va h.k.) operatsion tizimni o'zlaricha o'zgartiradilar. Android 11 dan Android 15 gacha bo'lgan versiyalar teng taqsimlangan bo'lishi mumkin.

## 3. Haqiqiy qurilma (Real Device) vs Emulyator / Simulyator

QA jamoasida ko'pincha savol tug'iladi: *"Kompyuterdagi Android Emulator yetarlimi yoki qo'lda haqiqiy telefon bo'lishi shartmi?"*

```
┌────────────────────────────────────────┐     ┌────────────────────────────────────────┐
│   Emulyator / Simulyator               │     │   Haqiqiy Qurilma (Real Device)        │
├────────────────────────────────────────┤     ├────────────────────────────────────────┤
│ ✓ Bepul va tez ishga tushadi           │     │ ✓ Haqiqiy teginish (Multi-touch)       │
│ ✓ CI/CD avtotestlari uchun qulay       │     │ ✓ Batareya qizishi va sarfi            │
│ ✗ Batareya sarfini ko'rsatmaydi        │     │ ✓ Biometrika (Face ID, Barmoq izi)     │
│ ✗ Haqiqiy kamera va sensorlar yo'q     │     │ ✓ Haqiqiy mobil internet (3G/4G/5G)    │
│ ✗ Teginish (Gesture) hissi sun'iy      │     │ ✗ Qimmat va alohida xarid talab etadi   │
└────────────────────────────────────────┘     └────────────────────────────────────────┘
```

<Callout type="info">
  **Oltin qoida:** Dastlabki sinovlar va avtotestlar uchun emulyatorlar qulay. Biroq **reliz oldi (Smoke / Acceptance)** sinovi albatta kamida ikkita haqiqiy qurilmada (bitta Android, bitta iPhone) o'tkazilishi shart!
</Callout>
