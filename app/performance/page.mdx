## Nima uchun Performance Testing muhim?

1. **Amazon tahlili:** Sahifa yuklanishining har 100 millisekundga sekinlashishi kompaniya savdosini 1% ga tushiradi.
2. **Kutilmagan Black Friday / Aksiyalar:** Yangi yil yoki chegirma kunlarida minglab xaridorlar bir vaqtda to'lov oynasiga kelganda server "qulab tushmasligi" kerak.
3. **Resurslar sarfi va Cloud xarajatlari:** Optimallashtirilmagan SQL so'rovlar yoki xotira sizib chiqishi (memory leak) AWS/Google Cloud server xarajatlarini asossiz oshirib yuboradi.
