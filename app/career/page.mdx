## QA Mutaxassisining O'sish Bosqichlari

```
[Junior QA] ────────► [Middle QA] ────────► [Senior QA] ────────► [QA Lead / SDET]
Qo'lda sinash,       API, SQL, Postman,    Arxitektura, CI/CD,   Butun sifat tizimi,
Test caselar,        Boshlang'ich          Murakkab avtomat-     Jamoa boshqaruvi,
Oddiy bug report     avtomatlashtirish     lashtirish, k6        Infratuzilma (DevOps)
```

1. **Junior QA Engineer:** Asosiy e'tibor — sinchkovlik, talablarni to'g'ri tushunish, professional Test Case va aniq Bug Report yozish.
2. **Middle QA Engineer:** API (Postman), SQL ma'lumotlar bazasi, Git va test avtomatlashtirish asoslarini (Playwright / Cypress) mustaqil qo'llay olish.
3. **Senior QA Engineer:** Tizim xavfsizligi, yuklama (Performance) sinovlari, test arxitekturasi va CI/CD jarayonlarini to'liq boshqarish.
4. **SDET (Software Development Engineer in Test):** Dasturchi darajasida kod yozuvchi, avtomatlashtirish freymvorklarini noldan quruvchi va infratuzilmani optimallashtiruvchi muhandis.
