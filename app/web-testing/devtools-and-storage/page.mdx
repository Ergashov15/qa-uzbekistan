# DevTools va Brauzer Xotirasi (Cookies & Storage)

Veb ilovada xatolik yuz berganda sahifani shunchaki qayta yangilash (Refresh) yetarli emas. Muammoning ildizi har doim brauzerning DevTools paneli va ichki xotirasida yotadi.

---

## 1. Chrome DevTools ning eng muhim oynalari

### 1.1. Network (Tarmoq) oynasi:
QA ning eng asosiy ish maydoni. Sayt ochilishi davomida yuborilgan barcha HTTP so'rovlar bu yerda ko'rinadi:
* **Headers:** So'rov qaysi URL ga, qanday metod (`POST`, `GET`) va qanday sarlavhalar (`Authorization: Bearer ...`) bilan ketgani.
* **Payload:** Serverga yuborilgan JSON ma'lumoti.
* **Response / Preview:** Server qanday javob qaytargani (`200 OK`, `400 Bad Request` va uning matni).
* **Disable Cache:** Sinov paytida brauzer eski fayllarni eslab qolmasligi uchun doimo yoqiq turishi shart bo'lgan tugma.

### 1.2. Console (Konsol) oynasi:
Brauzerda bajarilayotgan JavaScript xatoliklari (`Uncaught TypeError...`) bu yerda qizil rangda chiqadi. Agar tugma bosilganda hech narsa sodir bo'lmasa, birinchi navbatda konsolga qarash kerak.

---

## 2. Brauzer Xotirasi: Cookies vs LocalStorage vs SessionStorage

Veb ilova foydalanuvchi ma'lumotlarini (masalan, kirish tokeni yoki savatchadagi tovarlar) brauzerda qayerda saqlaydi?

| Xususiyat | Cookie | LocalStorage | SessionStorage |
| :--- | :--- | :--- | :--- |
| **Hajmi** | ~4 KB | ~5-10 MB | ~5-10 MB |
| **Saqlanish muddati** | Belgilangan muddatgacha (`Expires / Max-Age`) | Foydalanuvchi o'zi tozalamaguncha cheksiz | Veb brauzerning aynan shu oynasi (tab) yopilguncha |
| **Serverga uzatilishi** | Har bir HTTP so'rovda avtomatik serverga jo'natiladi | Faqat brauzerda qoladi, avtomatik ketmaydi | Faqat brauzerda qoladi |
| **Xavfsizlik bayroqlari** | `HttpOnly`, `Secure`, `SameSite` | Xavfsizlik bayroqlari yo'q (XSS ga moyil) | Xavfsizlik bayroqlari yo'q |

---

## 3. Cookie xavfsizlik atributlari (QA nimalarni tekshiradi?)

DevTools `Application -> Cookies` oynasida har bir cookie parametrini tekshirish lozim:

```
Name: session_token
Value: eyJhbGciOi...
HttpOnly: ✓ (Belgilangan bo'lishi shart!)
Secure:   ✓ (Faqat HTTPS orqali uzatiladi)
SameSite: Strict yoki Lax (CSRF hujumlaridan himoya)
```

1. **`HttpOnly`:** Ushbu bayroq qo'yilgan bo'lsa, brauzerdagi JavaScript kodi (`document.cookie`) ushbu tokenni o'qiy olmaydi. Bu foydalanuvchini XSS orqali sessiyani o'g'irlatishdan asraydi.
2. **`Secure`:** Cookie faqatgina xavfsiz shifrlangan `HTTPS` aloqasi orqali uzatilishini ta'minlaydi.
3. **`SameSite`:** Boshqa begona saytlardan turib bizning ilovamizga yashirincha so'rov yuborilganda bu cookie biriktirilmasligini kafolatlaydi (CSRF himoyasi).

<Callout type="info">
  **Sinov usuli:** Foydalanuvchi tizimdan chiqish (Logout) tugmasini bosganda, brauzer xotirasidagi barcha Cookie va LocalStorage ma'lumotlari to'liq tozalanayotganini tekshiring!
</Callout>
